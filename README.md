# 体征档案

给 AI 角色加一套会随时间变化的体征数值，每轮对话把读数注入提示词，并附带可视化页面。

## 功能

- 欲望值（0-100）、温度、残留量、状态四项体征，后台定时推进
- 每轮对话前自动注入当前读数，模型回复后再按关键词推进状态
- 时间推进：残留按速率自然吸收，档位无信号自动回落
- 状态机：无 / 运动 / 在位 / 已退出，各自带超时
- 可视化页面：状态图、参数、事件日志、手动调整
- 数值、词表、档位名、配色全部可在插件配置里改

## 安装

从插件市场安装：在 AstrBot 后台的插件页搜索「体征档案」，点安装。

手动安装：把 `astrbot_plugin_bio_status` 整个目录放进
`<AstrBot根目录>/data/plugins/`，然后在插件管理里启用，或重启 AstrBot。

日志出现 `[bio-status] 已启动` 即加载成功。

## 配置

全部配置项在 AstrBot 的插件配置界面修改。

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| tickMs | int | 3000 | 后台推进间隔，单位毫秒 |
| capacity | int | 200 | 残留量上限 |
| absorbPerHour | float | 4 | 每小时自然吸收的残留量 |
| injectAmount | int | 12 | 单次注入的残留量 |
| desireNormal | int | 30 | normal 档对应的欲望值 |
| desireMild | int | 50 | mild 档对应的欲望值 |
| desireFull | int | 90 | full 档对应的欲望值 |
| desirePounce | int | 100 | pounce 档对应的欲望值 |
| tempBase | float | 37.2 | 温度公式的基准值 |
| tempRise | float | 3.3 | 欲望满值时在基准上增加的度数 |
| stageDecaySec | int | 180 | 无信号多久降一档，单位秒 |
| thrustHoldSec | int | 20 | 运动状态保持时长，单位秒 |
| outHoldSec | int | 30 | 已退出状态保持时长，单位秒 |
| heatWords | list | 亲密 / 靠近 / 心动 / 想你 / 脸红 / 抱 / 贴 / 亲近 | 轻度信号词，命中即升温 |
| pounceWords | list | 扑上来 / 扑倒 / 忍不住了 | 强信号词，命中即拉到最高档 |
| injectWords | list | 灌 / 注入 / 填满 / 装不下 | 命中则增加残留量 |
| penWords | list | 进来了 / 深入 / 没入 | 命中则状态转为运动 |
| exitWords | list | 退出 / 结束 / 停下 | 命中则状态转为已退出 |
| satisfiedWords | list | 满足了 / 够了 / 舒服 | 命中则解除锁定并回落到常态 |
| stageLabels | dict | normal=平静 mild=微热 full=高涨 pounce=难耐 | 档位显示名，键固定只改值 |
| stateLabels | dict | none=无 moving=抽动中 inserted=在位 pulled=已退出 | 状态显示名，键固定只改值 |
| promptHint | text | 按上面这组读数决定你说话的分寸，不要自己报数字。 | 追加在读数后面的提示语，留空则只注入读数 |
| theme | dict | 见下 | 页面配色 |

`theme` 的键：`bg0` `bg1` `line` `line2` `fg` `dim` `faint` `accent` `accent2` `accent3`。
修改后页面会自动应用，刷新即可看到。

词表匹配规则：多字词命中就计数，单字词只在句子不超过 40 字时算一次，避免误触发。
把某个词表留空，等于关掉对应功能。

## 命令

- `/体征` 查看当前读数
- `/体征归零` 全部重置

## 页面

在 AstrBot 后台的「插件」页找到「体征档案」，点进去即可。

页面分三块：

- 左：视图切换（状态总览 / 事件日志 / 设置）
- 中：状态图与参数条
- 右：数值卡片（残留量、核心能量、欲望值、近期事件）

设置页可以拖欲望值滑条、切换档位、手动增减残留量。
窗口变窄时会自动切成单列布局。

## 注意事项

这是给角色扮演场景用的状态模拟，数值只在插件内部生效，
用来给模型提供一段参考读数，不影响任何实际行为，也不涉及真实设备或外部服务。

- 关键词匹配是纯字符串包含，不做语义判断，出现同样的字就会计数
- 回复文本取自模型最终回复，带工具调用的那一轮可能读不到
- 状态存档为单文件 JSON，只适合单进程运行
- 若宿主版本未提供页面 SDK，会退回直接请求接口
